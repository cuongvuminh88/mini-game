06 · Kế hoạch deploy

Lên mạng trên một máy ảo miễn phí.

Chạy nguyên Docker Compose hiện có trên 1 máy Compute Engine e2-micro ở us-central1, mở qua tên miền game.cuonguk.com. Tài liệu này là kế hoạch: chưa chạy lệnh nào.

Không đạt 100% miễn phí: địa chỉ IPv4 công khai gắn vào máy ảo không nằm trong Free Tier của e2-micro. Giá ở us-central1 là 0,005 USD/giờ, khoảng 3,65 USD/tháng. Free Tier của IP chỉ có 1 giờ/tháng. Máy ảo phục vụ web công khai thì phải có IP, nên khoản này không tránh được. Nếu billing account còn tín dụng dùng thử thì khoản này được trừ vào tín dụng (chưa kiểm tra).

Sơ đồ

Người chơi vào https://game.cuonguk.com. DNS trả về IP tĩnh của máy ảo. Tường lửa Google chỉ cho cổng 80 và 443 đi vào Caddy. Caddy cấp HTTPS miễn phí (Let’s Encrypt) rồi chuyển tiếp vào app Node.js, app nói chuyện với PostgreSQL trong cùng mạng Docker. Bạn quản trị máy qua SSH đi đường hầm IAP của Google, không mở cổng 22 ra Internet.

Cổng 3000 và 5432 không mở ra ngoài. Caddy là dịch vụ mới, chỉ thêm khi chạy trên máy ảo (file compose.prod.yaml), máy Mac vẫn chạy như cũ.

Máy chỉ có 1 GB RAM

Ba container cộng hệ điều hành phải vừa trong 1 GB. Kế hoạch là đặt trần RAM cho từng container, ép PostgreSQL dùng ít bộ nhớ, và thêm 2 GB swap làm đệm khi build image hoặc khi có đột biến.

PhầnTrần RAMCách đặt
Debian + Dockerkhoảng 250 MBKhông cài thêm dịch vụ nào khác
db (PostgreSQL)256 MBdeploy.resources.limits.memory: 256M và tham số shared_buffers=64MB, work_mem=2MB, maintenance_work_mem=32MB, max_connections=20, effective_cache_size=192MB
app (Node.js)192 MBlimits.memory: 192M và NODE_OPTIONS=--max-old-space-size=128
caddy96 MBlimits.memory: 96M
Swap2 GBFile /swapfile, vm.swappiness=10 để chỉ dùng swap khi thật cần

Lệnh tạo swap (chạy trong máy ảo)

sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
echo 'vm.swappiness=10' | sudo tee /etc/sysctl.d/99-swap.conf
sudo sysctl --system

File compose.prod.yaml sẽ thêm vào repo

File này chỉ ghi đè những gì khác với máy Mac. Chạy bằng docker compose -f compose.yaml -f compose.prod.yaml ….

services:
  app:
    ports: !override
      - "127.0.0.1:3000:3000"      # chỉ trong máy, người ngoài đi qua caddy
    environment:
      TRUST_PROXY: "1"             # đọc IP thật của người chơi từ caddy
      NODE_OPTIONS: --max-old-space-size=128
    deploy:
      resources:
        limits: { memory: 192M }

  db:
    command: ["postgres",
      "-c", "shared_buffers=64MB", "-c", "work_mem=2MB",
      "-c", "maintenance_work_mem=32MB", "-c", "max_connections=20",
      "-c", "effective_cache_size=192MB"]
    deploy:
      resources:
        limits: { memory: 256M }

  caddy:
    image: caddy:2-alpine
    ports: ["80:80", "443:443"]
    volumes:
      - ./Caddyfile:/etc/caddy/Caddyfile:ro
      - caddy_data:/data
      - caddy_config:/config
    depends_on: [app]
    restart: unless-stopped
    deploy:
      resources:
        limits: { memory: 96M }

volumes:
  caddy_data:
  caddy_config:

File Caddyfile

game.cuonguk.com {
  encode gzip
  reverse_proxy app:3000
}

Sửa code cần làm trước khi deploy

IP người chơi sau proxy: hiện lib/api.js lấy IP từ req.socket.remoteAddress. Khi đứng sau Caddy, mọi người chơi sẽ có chung IP của Caddy. Hậu quả: giới hạn 10 lần đăng ký / 10 phút và 5 lần đăng nhập sai / 15 phút bị tính chung cho tất cả mọi người, một người dò mật khẩu admin là khoá luôn cả bạn. Cần sửa: khi TRUST_PROXY=1 thì đọc IP từ header X-Forwarded-For do Caddy gắn.

Các bước deploy và cách kiểm tra

Làm đúng thứ tự. Mỗi bước có một ô kiểm tra màu xanh: chưa đạt thì dừng lại, đọc log, sửa rồi mới sang bước sau. Bước 1 đến 5 chạy trên Mac, bước 6 đến 11 chạy trong máy ảo, bước 12 chạy lại trên Mac.

Bước 0 · Đặt cảnh báo ngân sách

Trên web: Billing → Budgets & alerts → tạo ngân sách 5 USD/tháng cho project dapbosscuonguk, báo email ở 50%, 90%, 100%. Cảnh báo không tự tắt dịch vụ, chỉ gửi email.

Kiểm tra: trang Budgets hiện ngân sách mới, đúng project.

Bước 1 · Sửa code và thêm file cấu hình (trên Mac)

Sửa clientIp theo mục trên, thêm compose.prod.yaml và Caddyfile, commit và push lên GitHub.

docker compose -f compose.yaml -f compose.prod.yaml config --quiet && echo OK
docker compose up -d --build   # bản Mac vẫn chạy như cũ

Đạt khi in OK, game ở localhost:3000 vẫn chơi được, git status sạch.

Bước 2 · Bật API Compute Engine và IAP

gcloud services enable compute.googleapis.com iap.googleapis.com
gcloud services list --enabled | grep -E 'compute|iap'

Đạt khi thấy cả hai dòng.

Bước 3 · Giữ IP tĩnh

gcloud compute addresses create dap-sep-ip --region=us-central1
gcloud compute addresses list

Đạt khi thấy dap-sep-ip, trạng thái RESERVED. Ghi lại địa chỉ IP. Từ lúc này bắt đầu tính phí IP, nên làm tiếp bước 5 ngay.

Bước 4 · Tường lửa

gcloud compute firewall-rules create allow-web \
  --network=default --allow=tcp:80,tcp:443 --target-tags=web
gcloud compute firewall-rules create allow-ssh-iap \
  --network=default --allow=tcp:22 --source-ranges=35.235.240.0/20
gcloud compute firewall-rules delete default-allow-ssh default-allow-rdp
gcloud compute firewall-rules list --format="table(name,sourceRanges.list(),allowed[].map().firewall_rule().list())"

Đạt khi không còn rule nào mở tcp 22 hoặc 3389 cho 0.0.0.0/0.

Bước 5 · Tạo máy ảo

gcloud compute instances create dap-sep-vm \
  --zone=us-central1-a --machine-type=e2-micro \
  --image-family=debian-13 --image-project=debian-cloud \
  --boot-disk-size=30GB --boot-disk-type=pd-standard \
  --address=dap-sep-ip --tags=web
gcloud compute instances list
gcloud compute disks list

Đạt khi máy RUNNING, IP ngoài trùng IP ở bước 3, đĩa loại pd-standard 30 GB. Sai loại máy, vùng hoặc loại đĩa thì xoá máy và tạo lại ngay.

Bước 6 · Vào máy qua SSH

gcloud compute ssh dap-sep-vm --zone=us-central1-a --tunnel-through-iap
free -h
lsb_release -d

Đạt khi vào được dấu nhắc lệnh, thấy khoảng 1 GB RAM và Debian 13.

Bước 7 · Thêm 2 GB swap và cập nhật tự động

Chạy khối lệnh swap ở trên, rồi bật cập nhật bảo mật tự động:

sudo apt-get update && sudo apt-get install -y unattended-upgrades
sudo dpkg-reconfigure -plow unattended-upgrades
swapon --show
free -h

Đạt khi dòng Swap hiện 2.0Gi. Khởi động lại máy (sudo reboot) và kiểm tra lại, swap vẫn còn.

sudo apt-get install -y ca-certificates curl git

Đạt khi in “Hello from Docker!” và có phiên bản Compose.

Bước 9 · Lấy code và tạo .env

git clone https://github.com/cuongvuminh88/mini-game.git
cd mini-game
cp .env.example .env
nano .env          # điền mật khẩu MỚI, khác bản trên Mac

Mật khẩu database và admin dài ít nhất 20 ký tự, tạo ngẫu nhiên, ví dụ bằng openssl rand -base64 24.

ls -l .env
git status

Đạt khi .env có quyền -rw------- và git status không liệt kê .env.

Bước 10 · Trỏ tên miền

Ở nơi quản lý DNS của cuonguk.com: xoá bản ghi CNAME game đang trỏ GitHub Pages, thêm bản ghi A game → IP tĩnh ở bước 3. Trên GitHub, tắt custom domain của Pages để GitHub không giữ tên này. Làm bước này trước bước 11, vì Caddy cần DNS đúng mới xin được chứng chỉ HTTPS.

dig +short game.cuonguk.com

Đạt khi chỉ trả về đúng IP tĩnh. DNS có thể mất vài phút đến vài giờ để cập nhật.

Bước 11 · Khởi động

docker compose -f compose.yaml -f compose.prod.yaml up -d --build
docker compose -f compose.yaml -f compose.prod.yaml ps
docker compose -f compose.yaml -f compose.prod.yaml logs --tail=50 caddy app
docker stats --no-stream
free -h

Đạt khi cả 3 dịch vụ running (db healthy), log caddy có “certificate obtained successfully”, log app có “đã kết nối PostgreSQL”, RAM mỗi container dưới trần.

Bước 12 · Kiểm tra từ bên ngoài (trên Mac)

curl -sI https://game.cuonguk.com | head -1
curl -sI http://game.cuonguk.com | grep -i location
curl -s -o /dev/null -w "%{http_code} %{redirect_url}\n" https://game.cuonguk.com/admin
nc -vz -w 5 <IP-tĩnh> 3000
nc -vz -w 5 <IP-tĩnh> 5432

Đạt khi: HTTPS trả 200; HTTP chuyển sang https; /admin trả 302 về /admin/login; hai lệnh nc báo không kết nối được. Sau đó chạy lại các ca trong Kế hoạch test trên điện thoại thật, gồm đăng ký, chơi, đăng nhập admin, xuất CSV.

Bước 13 · Sao lưu database

Snapshot đĩa không miễn phí, nên sao lưu bằng pg_dump rồi kéo file về Mac, mỗi tuần một lần:

gcloud compute ssh dap-sep-vm --zone=us-central1-a --tunnel-through-iap --command \
 'cd mini-game && docker compose exec -T db sh -c "pg_dump -U \$POSTGRES_USER \$POSTGRES_DB"' \
 > backup-$(date +%F).sql

Đạt khi file backup-….sql trên Mac có dữ liệu (mở thấy CREATE TABLE players). File chứa email và số điện thoại: không commit, không gửi đi.

Xoá sạch sau khoá học

  1. Nếu cần giữ dữ liệu, chạy bước 13 lần cuối. Không cần thì bỏ qua.
  2. Xoá máy ảo (đĩa khởi động bị xoá theo): 
    gcloud compute instances delete dap-sep-vm --zone=us-central1-a
  3. Xoá IP tĩnh, nếu quên bước này sẽ mất khoảng 7,3 USD/tháng: 
    gcloud compute addresses delete dap-sep-ip --region=us-central1
  4. Xoá tường lửa: gcloud compute firewall-rules delete allow-web allow-ssh-iap
  5. Kiểm tra không còn gì: gcloud compute instances list, gcloud compute addresses list, gcloud compute disks list đều rỗng.
  6. Cách chắc nhất là xoá cả project, mọi tài nguyên dừng ngay và bị xoá hẳn sau 30 ngày: 
    gcloud projects delete dapbosscuonguk
  7. DNS: xoá bản ghi A game, hoặc trỏ lại GitHub Pages.
  8. Xoá các file backup-*.sql trên Mac khi không còn cần dữ liệu người chơi.
  9. Tháng sau mở Billing → Reports, chắc chắn chi phí của project về 0.
